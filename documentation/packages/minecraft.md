# Minecraft

## Java Settings

- **Minimum Memory Usage (-Xms)**
    - <= 4 GiB System RAM
        - 512 MiB
    
    - 6 GiB System RAM
        - 1024 MiB

    - \>=8 GiB System RAM
        - 2048 MiB

- **Maximum Memory Usage (-Xmx)**

    - **System RAM Limits**
        - <= 4 GiB System RAM
            - 1024 MiB
            
        - 6 GiB System RAM
            - 2048 MiB
            
        - \>= 8 GiB System RAM
            - 4096 MiB
        
    - **Modding Levels**
        - Vanilla/Light Modding
            - 4096 MiB
            
        - Medium Modding
            - 6144 MiB
            
        - Heavy Modding
            - 8192 MiB
        
- **PermaGen Size (-XX:PermSize)**
    - 128 MiB
