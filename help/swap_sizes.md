# Swap Sizes
## Without Hiberation 
- **<=2 GiB System RAM**
    - 2 GiB swap size
- **4-8 GiB System RAM**
    - 4 GiB swap size
- **12 GiB System RAM**
    - 6 GiB swap size
- **>=16 GiB System RAM**
    - 8 GiB swap size
    
## With Hiberation
- **<=1 GiB System RAM**
    - 2 GiB swap size
- **2 GiB System RAM**
    - 4 GiB swap size
- **4 GiB System RAM**
    - 6 GiB swap size
- **6 GiB System RAM**
    - 8 GiB swap size
- **8 GiB System RAM**
    - 10 GiB swap size
- **12 GiB System RAM**
    - 14 GiB swap size
- **16 GiB System RAM**
    - 18 GiB swap size
- **>=24 GiB System RAM**
    - Hibernation not recommended
