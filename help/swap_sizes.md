# Swap Sizes

# Without Hiberation

- **<=2 GiB RAM**
    - 1 GiB swap size
- **4-8 GiB RAM**
    - 2 GiB swap size
- **12-16 GiB RAM**
    - 4 GiB swap size
- **>=24 GiB RAM**
    - 8 GiB swap size
    
# With Hiberation

- **<=1 GiB RAM**
    - 2 GiB swap size
- **2 GiB RAM**
    - 4 GiB swap size
- **4 GiB RAM**
    - 6 GiB swap size
- **6 GiB RAM**
    - 8 GiB swap size
- **8 GiB RAM**
    - 12 GiB swap size
- **12 GiB RAM**
    - 16 GiB swap size
- **16 GiB RAM**
    - 24 GiB swap size
- **24 GiB RAM**
    - 32 GiB swap size
- **32 GiB RAM**
    - 48 GiB swap size
- **48 GiB RAM**
    - 64 GiB swap size
- **64 GiB RAM**
    - 96 GiB swap size
- **128 GiB RAM**
    - 196 GiB swap size
