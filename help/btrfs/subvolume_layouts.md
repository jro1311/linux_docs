# Subvolume Layouts
## Single Distro (Recommended)
- `@` mounted as `/`
- `@home` mounted as `/home`
- `@flatpak` mounted as `/var/lib/flatpak`

## Multi Distro
- `@arch` mounted as `/` when booted into Arch
- `@debian` mounted as `/` when booted into Debian
- `@fedora` mounted as `/` when booted into Fedora
- `@arch_home` mounted as `/home` when booted into Arch
- `@debian_home` mounted as `/home` when booted into Debian
- `@fedora_home` mounted as `/home` when booted into Fedora
- `@flatpak` mounted as `/var/lib/flatpak`
